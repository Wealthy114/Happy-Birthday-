# Pastor David Birthday Website

A responsive birthday greeting website made with plain HTML, CSS, and JavaScript. It includes the provided photos, a heartfelt birthday prayer, responsive layout, smooth scrolling, a confetti celebration, and an optional short synthesized chime.

## Run it
1. Extract `Pastor_David_Birthday_Website.zip`.
2. Open `index.html` in a modern browser.
3. Keep the `css`, `js`, and `images` folders beside `index.html`.

No build tools or server are required. Google Fonts uses an internet connection; the site falls back to system fonts if unavailable.

## Project structure
- `index.html` — page content and sections
- `css/style.css` — styling, responsive layouts, animations and colours
- `js/script.js` — buttons, confetti, toast messages, and optional chime
- `images/` — the three photos provided for this greeting

## Customization
- Edit the greeting text in `index.html`.
- Replace photos in `images/` while keeping the same filenames, or update the corresponding `src` paths in `index.html`.
- Update the colour variables at the top of `css/style.css`.


## Background worship music
The page embeds the official YouTube upload of **“Fragrance to Fire” by Dunsin Oyekan**. It attempts muted autoplay when the page opens; tap **Enable music** to request playback with sound. Autoplay with sound cannot be guaranteed because browsers and mobile devices apply their own autoplay rules. An internet connection is required to stream the track.
